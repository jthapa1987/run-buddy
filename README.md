# 🌟 Run Buddy

A responsive fitness landing page built with **semantic HTML** and **modern CSS techniques**.  
This project demonstrates **layout fundamentals**, **mobile‑first design**, and **component‑based styling**.

---

## ⭐ Features
- 🎯 **Hero section** with call‑to‑action  
- 📐 **Flexbox‑based layout**  
- 📱 **Responsive design** using media queries  
- 📝 **Contact form section**  
- 🗂️ **Clean folder structure** and organized CSS  
- 🌍 **Fully deployed** using GitHub Pages  

---

## 🛠️ Technologies
- **HTML5**  
- **CSS3** (Flexbox, Media Queries)

---

## 📁 Project Structure
- `index.html` — main landing page  
- `assets/css/style.css` — primary styles  
- `assets/css/secondary-styles.css` — additional styling  
- `assets/images/` — project images
